# Sales Data Analysis – EDA Project

## Project Overview

This project focuses on analyzing sales data to understand business performance, customer behavior, product sales, and profit trends. Exploratory Data Analysis (EDA) is performed using Python to identify useful insights and patterns from the dataset.

## Dataset

The dataset contains three sheets: Orders, Customers, and Products. These datasets include information about sales transactions, customer details, product categories, payment methods, sales channels, and order status.

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook are used for data cleaning, analysis, and visualization.

## Analysis

The project explores monthly sales trends, top-selling products, category-wise sales, customer segment performance, state-wise sales, and sales channel performance. It also analyzes payment methods, order status, discounts, and profit patterns through different visualizations.

## Objective

The main objective is to understand sales performance, identify important business trends, and generate meaningful insights that support better business decisions.
